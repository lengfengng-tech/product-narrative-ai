# 单页设计简报

每页先完成简报，再制作。简报是 AI 的设计决策，不是交给脚本填空的表单。简单页可精简字段，复杂页必须写清事实和状态边界。

```text
页码 / 章节：
本页结论（精确标题）：
听众看完必须理解的一件事：
受众 / 角色视角 / 时间状态：
已确认事实与信息来源：
固定文案（标题、节点、注释）：
与前后页传递的对象或结果：
跨页案例必须沿用的条件：
主视觉及选择理由：
主题与视觉角色（主色、辅助色、语义色如何使用）：
不能出现的误解、状态或未证实能力：
```

## 页面制作指令骨架

以下骨架可用于图像生成、原生排版或委托其他制作工具。替换花括号内容，不原样照抄；参考图只提供需要借鉴的版式特征。

```text
制作一页中文商务产品方案，{画幅与输出格式}。

汇报对象与目的：{受众、使用场景、期望动作}
本页结论：{精确标题}
本页只解释：{一件事}
事实与固定文案：{完整内容，不扩写未确认能力}
主视觉：{图形类型、对象、方向、构图与选择理由}
角色与状态边界：{用户、AI、平台、业务结果等}

主题：{自主确定或用户指定的主题名称}
画布与表面：{颜色}
正文与说明：{颜色及层级}
主色：{颜色及使用位置}
辅助色与语义色：{仅在需要时定义}
字体、线条、图标、圆角与留白：{具体规则}

采用专业、克制、适合正式汇报的商务风。让中性色承担主要面积，颜色只表达层级、分类或状态。保持图标视觉居中、表格对齐、正文投屏可读。
不循环使用彩色卡片，不用大面积艳色和彩色边框抢占注意力，不添加装饰机器人、光效、虚构指标、无意义流程节点或不可用的假控件。
```

制作后由 AI 对照简报评审，而不是把生成结果直接视为完成。文字或业务关系错误时修正对应页；主题显得花哨时减少色彩，不靠模糊、缩小或增加装饰掩盖问题。
